    add_linkBot 招待URL

    このURLを友達に共有すると、友達が自分のDiscordサーバーにBotを追加できます。

    card_giftcard招待コード管理

    1. 「新規発行」でコードを生成し、コピーして友達に共有する
    2. 友達がこの管理画面のURLにアクセスし、「アカウント作成」タブを開く
    3. Discord ユーザーID・ユーザー名・パスワード・招待コードを入力して登録
    4. 友達がログイン後、設定画面で自分の Gemini API Key を登録する
    5. 友達が自分の Discord サーバーに Bot 招待URLでBotを追加する（招待URLは上の「Bot 招待URL」カードから取得）
    warning
