    先生ご自身の Gemini API Key と使用するモデルを設定してください。

    robot_2Discord 独自Bot ＆ ペルソナ設定

    任意設定

    先生独自の Discord Bot Token や、AIのペルソナ（システム指示）をカスタマイズできます。未設定の場合は、システムデフォルトのボットおよび「早瀬ユウカ」のペルソナが適用されます。

    ※独自Botを使用しない場合は空欄にしてください。
    ※キャラクター設定、話し方、行動指針などを自由に記述できます。

    googleGoogle アカウント連携 (OAuth2)

    Google カレンダーの同期や Google Drive へのデータバックアップを行うために、システム共通のセキュアな認証基盤を利用して Google アカウントとの連携を行います。

    システム構成ステータス (`config.yaml`)

    現在ロードされているサーバー設定です。機密情報は自動的に安全にマスクされています。

    cloud_syncGoogle Drive バックアップ

    Beta

    データベースや設定ファイル、プレイブックのデータをGoogle Driveへ安全にバックアップします。

    calendar_todayGoogle連携カレンダー管理

    同期対象のGoogleカレンダーIDを追加または削除できます。変更内容は `config.yaml` に即時反映されます。

    lockAI認証情報管理 (AI Credentials)

    SECURE

    AIエージェント（ユウカ）が自動ブラウジング等でログインするために使用するユーザー名とパスワードを安全に登録します。パスワードはAES-256-GCMにより強固に暗号化され、必要な時にのみオンデマンドで復号されます。

    対象サービス名 ユーザー名 (ID) パスワード 最終更新 操作

    memoryユウカの記憶管理

    MEMORY

    ユウカがDiscordで学習した定型情報の一覧です。AIが家計記録などの際に自動参照します。

    warning

    会計管理人よりお知らせ

    設定ファイルを直接編集する場合は、ボットプロセスを再起動する必要があります。設定内容はMillennium生徒会セミナー局の監査対象となりますので、計画的かつ慎重に変更を行ってください。
