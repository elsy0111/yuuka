# 家計管理 ルール・指示書 (Expenses)

このファイルはユーザーから指示された家計管理のルールや定型情報をAIが記録・参照するためのドキュメントです。
ユーザーの指示により随時更新されます。

## 記録ルール

- 金額は割引後の実際に支払った金額を記録する
- 購入もと (purchase_source) はユーザーが明示した名前のみ使用する（推測禁止）
- 割引があった場合のみ description に「(割引〇〇円引き)」を記載する

## カテゴリ対応表

| 品目・キーワード | カテゴリ |
|----------------|---------|
| バス、電車、交通系 | 交通費 |
| 食料品、飲食 | 食費 |
| ゲーム、アニメグッズ | 娯楽 |
